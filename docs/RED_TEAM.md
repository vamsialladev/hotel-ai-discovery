# Red team

This repo is the discovery pack (interviews, problem selection, statement of work, pricing, security answers). It
has no app and no model, so there's nothing to attack here. The scripts in `scripts/` work only on
files in this repo.

The red-team work for the system this pack proposed is in the repos that built it:
